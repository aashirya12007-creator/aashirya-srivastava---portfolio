How to Run Live in VS Code:
1. Unzip this folder and open it in VS Code (File -> Open Folder...).
2. Install the "Live Server" extension in VS Code (by Ritwick Dey).
3. Right-click `index.html` and select "Open with Live Server" (or click "Go Live" at the bottom-right).
4. The first time you submit the Contact Me form from Live Server or a live website, check
   aashirya12007@gmail.com for a one-time FormSubmit activation email and click "Activate Form".

How to Publish Live Online (Free):
- Netlify Drop: Drag and drop this entire folder onto https://app.netlify.com/drop
- GitHub Pages: Upload these files to a GitHub repository and enable Settings -> Pages.
